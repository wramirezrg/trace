# Security Policy

## Scope

This repository contains documentation and media only — it does not contain executable code, so
there is no attack surface here beyond the standard risks of any static content repository.

This policy covers vulnerabilities in **the TRACE application itself** (the software this
repository documents), as well as anything found on the [www.siganor.com](https://www.siganor.com) website.

## Reporting a Vulnerability

If you believe you've found a security vulnerability in TRACE or www.siganor.com, please report it
responsibly:

- Email: [info@siganor.com](mailto:info@siganor.com)
- Please include: a description of the issue, steps to reproduce, the TRACE version affected
  (if applicable), and your assessment of impact.

**Please do not open a public Issue for security vulnerabilities.** Use email so the issue can be
assessed and addressed before public disclosure.

## What to expect

- Acknowledgement of your report within a few business days.
- An assessment of the issue and, if confirmed, a plan and timeline for a fix.
- Credit in the release notes, if you'd like it, once the issue is resolved.

## Supported Versions

TRACE does not currently maintain multiple parallel supported versions. Security reports are
evaluated against the most recent release.
