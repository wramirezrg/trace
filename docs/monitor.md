# Live Monitoring

![Live Monitoring](../media/monitor.png)

The core of TRACE: a direct, real-time view of PLC signal behavior.

## What it does

Live Monitoring reads signals from PLC-connected equipment and plots them as they happen, so a
fault is visible the moment it occurs instead of being reconstructed afterward from memory or a
maintenance log.

## Capabilities

- **Multiple synchronized graphs** — track several signals across independent graph windows at
  the same time
- **Digital events** — on/off signal transitions rendered clearly on their own timeline
- **Analog trends** — continuous numeric values plotted live
- **Color customization** — assign colors to signals so a busy chart stays readable
- **Recording** — capture a live session for later analysis
- **CSV export** — pull recorded data into spreadsheets or other analysis tools
- **Signal organization** — group and manage the signals being watched
- **Independent graph windows** — separate machine sections or subsystems into their own views

## Why it matters

Intermittent faults are the hardest kind to troubleshoot. By the time someone looks at the
control panel, the moment has already passed. Live Monitoring is built to be running *before*
the fault happens, so the evidence is already on screen when it does.
