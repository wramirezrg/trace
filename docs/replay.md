# Replay

![Replay](../media/replay.png)

Not every fault can be watched live. Replay is built for the ones that already happened.

## What it does

Replay loads a previously recorded monitoring session and lets you step back through it, so a
machine sequence can be analyzed after the fact with the same clarity as watching it live.

## Capabilities

- **Load recorded sessions** — bring in one or more previously captured recordings
- **Replay troubleshooting sessions** — step through exactly what the signals were doing
- **Time cursors** — place two cursors on the timeline to compare specific moments
- **Time measurements** — read the precise duration between two events
- **Machine sequence analysis** — follow a multi-step process from start to finish
- **Visual event correlation** — see how multiple signals relate to one another in time

## Why it matters

A lot of industrial troubleshooting comes down to timing: which signal changed first, how long a
step took, whether an interlock released before or after it should have. Replay turns a recording
into an answer instead of a guess.
